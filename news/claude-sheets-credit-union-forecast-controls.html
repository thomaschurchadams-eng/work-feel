Claude Sheets Can Edit a Forecast. It Can’t Protect Key Ranges Yet

November 11, 2026

By CreditUnionAI News Staff

FinanceGenerative AI

Anthropic’s spreadsheet beta can change formulas in shared cells, but it lacks protected ranges. That makes a copy of a forecast a better test than the official workbook.

Anthropic released Claude Sheets in beta on November 10, giving teams a spreadsheet where Claude and staff can edit the same cells. The tool can create tabs and change formulas, and Anthropic says it highlights model edits. Its documentation also lists a control it doesn’t have yet: protected ranges.

For a credit-union finance team, that matters when an assumption, a source figure and an output sit in the same workbook. A faster edit to a deposit-growth scenario is useful only if staff can tell which inputs changed, reproduce the result, and keep unapproved changes out of the forecast used for decisions.

What the beta can and can’t do

Anthropic’s Sheets documentation says the beta supports formulas across tabs and exports to XLSX or CSV. It does not support protected ranges, pivot tables, macros, VBA or Power Query, and Sheets cannot pull live data from connected apps. An export option does not establish that a credit union’s existing workbook, formulas or controls will carry over.

Sheets is on by default for Team and off by default for Enterprise, according to Anthropic. The November 19 Enterprise default date in the same announcement applies to the separate Claude Data feature, not Sheets. Anthropic has not reported credit-union adoption or performance for the Sheets beta.

Run one forecast change in a copy

In an approved test environment, start with a synthetic copy of a deposit-cost forecast. Ask Claude to change one funding assumption and identify every cell it edited. Have a second person compare the input range and formulas against the baseline, then open the XLSX export in the institution’s approved spreadsheet tool and recompute a control total. Check that unrelated assumptions, units and forecast periods stayed unchanged.

Keep the official forecast and sign-off outside the beta until the team can reproduce changes and demonstrate the required controls. If a formula changes without a clear reason, or the output doesn’t reconcile after export, treat the result as a draft. The NCUA’s AI resources provide broader context on vendor due diligence, data protection and monitoring; they do not endorse this product.
